<h1>Hey 👋, I'm Kai.</h1>

Java Backend Developer

I build backend applications and REST APIs with Java/Kotlin, Scala, Spring, PostgreSQL, Docker, and Kubernetes.

I have one year of professional experience working on a commercial MMO game server project with an architecture similar to L2J, working across the Java server backend, databases, and surrounding web infrastructure. This gave me hands-on experience with large legacy codebases and the architecture behind MMO platforms.

Outside of backend development, I'm interested in server architecture, legacy systems, MMO game servers such as World of Warcraft, Lineage II, and Final Fantasy XI, and the technologies behind Unreal Engine 2-3. I also enjoy modernizing the web interfaces that accompany these projects, using React, Next.js, and TypeScript to bring legacy web infrastructure up to modern standards.

As a hobby, I experiment with Rust and C/C++, mostly exploring systems programming, game development, and lower-level technologies.
